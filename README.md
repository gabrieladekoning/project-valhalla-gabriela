#### Setting Up Environment Variables
In this project, Docker environment variables are being used to securely store sensitive data.

The environment variables that you'll need to configure to run the project are contained in an env.template file in the root of the project directory. To use this template file, you should rename it to .env. This .env file will be read by Docker Compose.

These are the environment variables which need to be set with your own values:
```
MYSQL_ROOT_PASSWORD= # MySQL root password
MYSQL_USER= # MySQL username
MYSQL_PASSWORD= # MySQL password

KC_DB_USERNAME= # Keycloak DB username
KC_DB_PASSWORD= # Keycloak DB password

KEYCLOAK_ADMIN= # Keycloak admin username
KEYCLOAK_ADMIN_PASSWORD= # Keycloak admin password
```
After setting these variables, you can proceed to start the services using Docker Compose.

> **Note** 
> When running for the first time, re-run keycloak container again after which it will properly work

#### Keycloak Setup
Project Valhalla uses Keycloak, an open-source Identity and Access Management solution, for user authentication.

Keycloak is configured and run via Docker. After you start the Docker containers, you can access the Keycloak Admin Console at http://localhost:8180/auth.

1. Open your browser and navigate to http://localhost:8180/auth.
2. Click on the Administration Console link.
3. The default username is admin and password is admin.
4. Once logged in, you need to create a new Realm named application-users.
5. After creating the realm, create a client application with the following details:
    * Client ID: access-control-client
    * Toggle 'Client authentication' and 'Authorization'
    * Set Valid redirect URI to http://localhost:8180/*

   Make sure to save the client's secret key generated by Keycloak. This key is used in the Access Control Service's application.yml configuration file.

> **Note** 
> All these settings (such as realm name, client ID, and client secret) should match the configurations set in your application.yml file.

## Usage

_(work in progress)_
The services are exposed on the following ports:

* **Eureka Service** - 8761
* **Gateway Service** - 8080
* **Access Control Service** - 8090

After setting up, you can test the application by making requests to the various endpoints exposed by the Access Control Service. For authentication, make sure to use the Keycloak token obtained after logging in.
